About

AniSpeakArchive

A research-grade, corpus-scale search engine for animal communication and bioacoustics literature, designed for an ACL-style system demonstration.

What is the task?

AniSpeakArchive targets a broad interdisciplinary corpus with three equally valid research traditions:

  • Biological: ethology, ecology, behavioral biology of communication (call function, acoustic ecology, sexual selection, signaling evolution).
  • Computational: ML/DL/signal processing on animal signals (species ID, call-type classification, PAM pipelines, foundation models).
  • Animal linguistics: structural analysis (syntax, compositionality, referential calls, repertoire structure, turn-taking).
Strict relevance rules (high precision)

A paper is marked irrelevant only when it is clearly outside animal communication/signaling. Typical exclusions:

  • Human speech/NLP with no animal signal data and no explicit animal comparison.
  • Medical studies using animals only as disease models (animal as a tool, not the subject of communication study).
  • General ML/robotics/vision with no biological animal data.
  • Industrial signal processing (machines, vibration, motors, pipelines).
  • Animal-named optimization algorithms (e.g., whale optimizer) without animal signals.

How search works (online)

Search is hybrid and optimized for research workflows: start with a seed topic query, then narrow using facets.

1) Hybrid retrieval
BM25 full-text + dense embeddings, fused with Reciprocal Rank Fusion (RRF).
2) Cross-encoder re-ranking
Top candidates are re-scored with a cross-encoder to improve ordering for nuanced queries.
3) Facets and evidence
Filters come from bibliographic fields and title/abstract extraction; inferred labels include evidence phrases.
Retrieval stack (as configured)
  • Dense encoder: BAAI/bge-m3 (embeddings)
  • Lexical: LanceDB Full-Text Search (BM25)
  • Fusion: RRF over lexical + dense
  • Re-ranker: BAAI/bge-reranker-base

End-to-end corpus construction (offline)

The web corpus is the end of a larger pipeline built to scan OpenAlex at scale and produce a high-quality animal communication subset.

1) Data source: OpenAlex

We start from OpenAlex snapshots and apply conservative filters before classification.

  • Records checked: 410,527,495
  • Filtered by year/lang/retracted: 123,069,553
  • Filtered by type: 6,763,285
  • Filtered by status: 162,665,638
  • Deduplicated: 19,853

2) Broad pre-filter + classifier

A SciBERT classifier is used to retain recall and avoid missing biological (non-ML) animal communication papers.

  • Sent to BERT: 118,009,166 (28.75%)
  • BERT positives: 100,940 (threshold=0.4)
  • Time: 1,658.0 min; Throughput: 4,127 rec/s
SciBERT training results (held-out test set)
  • Macro-F1: 0.9555 (primary ablation metric)
  • Recall: 0.9632 (optimized to minimize misses)
  • Precision: 0.9469; AUROC: 0.9805
  • Confusion: TP=1909, FP=107, FN=73, TN=1960

3) Metadata extraction prompt (condensed)

For each relevant paper, a structured extractor assigns schema fields using only title + abstract, with strict evidence requirements. This powers facets like species, contexts, stages, features, domains, and resource flags.

Extractor policy highlights
  • Strict verification: irrelevant only for clear out-of-scope cases (human-only NLP, industrial signals, etc.).
  • Evidence-backed tagging: every inferred label must cite a real phrase from the title/abstract when applicable.
  • Species discipline: extract only explicitly mentioned animals; bats are always category = Bat.
  • Resource flags: Has code/dataset/benchmark are true only when explicitly stated in title/abstract.
  • Under-assign > hallucinate: if evidence is missing, leave the field empty.

4) Species canonization

Raw species mentions are cleaned (plural normalization, prefix stripping, noise removal), then resolved against GBIF where possible. The resulting canonical forms drive the taxonomy facets and leaderboards.

  • Cleaned unique mentions: 17,383
  • Strict scientific-like: 7,887; Vernacular/other: 9,463
  • GBIF usageKey coverage: 12,369 / 17,383 (71.2%)

UI/UX design choices for the demo

Seed query first
Facets narrow within a topical slice; they are not intended to replace topical retrieval.
Resource buttons
Has code/dataset/benchmark are clickable toggles (explicit evidence only).
Analytics is cached
Expensive groupby/explode analytics responses are cached on disk, keyed by LanceDB fingerprint.
Sentinels are hidden by default
The taxonomy sentinel "Others" is hidden by default in leaderboards (toggle available).
